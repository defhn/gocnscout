## 脚本

- `package.json` 列出的展会导入、清洗、验证、同步脚本仍被项目命令引用，保留。数据库导入和同步会修改数据，执行前核对目标、权限、备份和参数。
- `scripts/database/` 是迁移备份与恢复工具，保留；恢复只适用于符合脚本约束的目标数据库。
- 其余生成、同步、修复、研究和 PDF 脚本属于人工工具，不等于线上自动流程。部分会调用付费 API、读取本机特定路径或修改数据库。运行前先阅读代码并确认用途、配置和目标；不要直接批量发布。
- 本次移除了依赖已删除旧视频文件的 PDF 脚本、针对旧机器路径的两条批处理启动脚本、一次性修复五篇文章的脚本，以及依赖过时 SEO 方案且可能自动发布的旧生成脚本。移除了会构造模拟企业信用代码的旧报告脚本，避免把模拟数据当成真实资料。

本说明不是全量功能验收，也未运行任何会调用外部 API 或修改数据库的脚本。
