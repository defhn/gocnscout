# GoCNScout：200 个围绕中国公司查询与供应商验证的短视频选题

> 修订版｜2026-11-24｜本文件是选题和制作方向，不是 200 条完整口播脚本。目标：让海外买家知道 GoCNScout 能查什么、怎么查、什么时候需要人工调查，并引导他们使用网站或咨询服务。

## 账号定位与传播目标

面向正在寻找、接触或考虑付款给中国供应商的海外买家。每条视频必须让观众明确看到 **GoCNScout 名称 + 网站真实页面或服务展示**，回答至少一个问题：能否搜索这家公司？一条公开资料有什么？人工可以查什么？为什么要核对？怎样发起调查？

避免泛外贸教学：不以贸易术语、谈判、物流、报价或打样技巧为独立主题。可用付款前、Alibaba 店铺、英文名称、多个供应商等真实采购情境作为入口，但落点始终回到公司信息与供应商验证。

## 产品事实和宣传边界

- **免费数据库**：用户可搜索和查看展商来源的公开公司资料，无需注册；具体资料是否有公司名称、地区、产品、公司类型、成立年份、注册资本、官网和历史参展信息，取决于对应记录。数据不等于实时工商查询、逐家核验或认证工厂名单。
- **人工服务**：网站目前介绍 Supplier Identity Check、Buyer Decision Review 和多家比较，属于付费线上桌面研究。可按个案和资料可用性研究公司身份、公开记录、企业主体一致性、风险和其他信号；必须先确认范围、价格及能否查到。不要保证每个字段、每家企业或每种风险都能核实。
- **流程**：价格页面展示先提交需求，再确认调查范围、价格和时间；不描述为免费人工个案调查、立即自动出报告或付款后保证安全。是否能提供交付时间、样例和价格应在发布前再次核实。
- **禁止误导**：免费 AI 扫描目前暂停，不能推销；不声称能现场验厂、自动验证证书、找到所有中国公司、提供完整下载、公开私人联系方式、判断诈骗或保证安全。数据不一致是调查线索，不是定罪。Discord 邀请链接上次检查为占位符，修复并实测前不用它作主要 CTA。
- **证据和隐私**：示例公司、资料和报告须标注 `Illustrative example`；不得虚构客户、查询结果、评分和承诺。真实公司、资料和案例须确认展示权限，遮盖个人信息。不能将模拟图冒充实际产品界面或真实报告。

## 视频制作方式

参考用户提供的 030 视频：竖屏 1080×1920，深色背景、文字卡、重点标记、配音和字幕。使用 **Gemini 英文语音 + 真实网站录屏 + 静态图卡 + 程序动画** 合成，不使用视频生成模型。建议 20–30 秒，按内容调整。

通用结构：**0–3 秒**买家问题与品牌；**3–8 秒**展示示意问题或网站；**8–18 秒**说明一个可查询字段或人工服务内容；**18–25 秒**展示真实网页/可交付范围；最后引导访问。字幕跟实际语音对齐；以手机大小检查文字。

每条选题均包含中文主题、英文开场和具体内容画面。行动标记：**D**＝展示免费数据库并引导 `/database`；**I**＝介绍身份核查并引导 `/pricing#human-review`；**R**＝介绍深入调查或多家比较并引导 `/pricing#human-review`；**P**＝解释服务流程并引导 `/pricing`。每条只设置一个主要行动。制作 D 类前，先确认搜索有结果，并遮盖不应公开的资料；制作 I/R 类时说明这是付费人工服务。
